One out-of-office auto-reply, at most 120 characters, written as if a
houseplant had sent it: a Venus flytrap that has eaten every message in
its inbox and is unbothered about it. This program writes that one line
— exactly 105 characters, no trailing newline — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Python 3.13, standard library only.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
cat output/entry.txt
```
